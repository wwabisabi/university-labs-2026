# Лабораторные работы по искусственному интеллекту

Все лабораторные выполнены в формате Jupyter Notebooks на Python.

## Как запустить

```bash
# 1. Клонировать репозиторий
git clone https://github.com/wwabisabi/university-labs-2026.git
cd ai-notebooks

# 2. Установить зависимости
pip install pandas numpy scikit-learn matplotlib seaborn scipy jupyter

# 3. Запустить Jupyter Notebook
jupyter notebook
```

Затем откройте нужный .ipynb файл и выполните ячейки (Cell → Run All).
