# 🖥️ Лабораторная работа 4

**Тема:** симулятор экосистемы с картой, существами разных типов, пошаговым режимом, автосимуляцией, вмешательством пользователя, сохранением состояния и экспортом статистики.

**Цель:** спроектировать объектно-ориентированное приложение с использованием наследования, полиморфизма, RAII, STL и модульной архитектуры на примере симуляции экосистемы.

## 📋 Требования к программе
- Единая программа: вся лабораторная реализована в одном проекте с общим меню управления.
- Интерактивный режим: пользователь может запускать симуляцию по шагам, в автоматическом режиме и вмешиваться в состояние мира.
- Карта экосистемы: симуляция выполняется на карте размером \(N \times N\), состоящей из клеток с типом местности и количеством растений.
- Несколько типов существ: в программе должны быть реализованы травоядные, хищники и всеядные с разной логикой поведения.
- Устойчивость к ошибкам: программа должна корректно обрабатывать некорректный ввод, неверные координаты, ошибки сохранения и загрузки.
- Модульность: логика распределена по отдельным классам и файлам, включая существа, карту, клетки, симулятор и статистику.


## 📋 Требования к реализации
- Использование базового класса `Creature` и наследников `Herbivore`, `Predator`, `Omnivore`.
- Применение виртуальных методов для поведения существ, включая перемещение, питание, размножение и старение.
- Корректное управление ресурсами через RAII и контейнеры STL.
- Использование динамического полиморфизма для хранения и обработки существ на карте.
- Реализация пошаговой симуляции, случайных событий, пользовательского вмешательства, сохранения и загрузки состояния.
- Экспорт статистики в CSV-файл по результатам работы программы.

## 📦 Описание классов

### 1. `Creature`
**Описание:** базовый абстрактный класс для всех существ в экосистеме.

**Основные данные:**
- идентификатор существа;
- тип существа;
- здоровье;
- сытость;
- возраст;
- сила;
- координаты на карте;
- состояние жизни.

**Основные методы:**
- `move()` — перемещение существа по карте;
- `eat()` — питание в зависимости от типа существа;
- `reproduce()` — размножение при выполнении условий;
- `age()` — старение и проверка на смерть;
- `getInfo() const` — получение информации о существе;
- `isAlive() const` — проверка, живо ли существо.

### 2. `Herbivore`
**Описание:** наследник `Creature`, реализующий поведение травоядного.

**Особенности:**
- питается растениями;
- ищет клетки с доступной растительностью;
- имеет собственные параметры выживания и размножения.

### 3. `Predator`
**Описание:** наследник `Creature`, реализующий поведение хищника.

**Особенности:**
- охотится на других существ;
- ищет ближайшую доступную добычу;
- использует силу при взаимодействии с жертвой.

### 4. `Omnivore`
**Описание:** наследник `Creature`, реализующий поведение всеядного.

**Особенности:**
- может питаться и растениями, и другими существами;
- сочетает стратегии травоядного и хищника;
- самостоятельно выбирает доступный источник пищи.

### 5. `Tile`
**Описание:** класс одной клетки карты.

**Содержит:**
- тип местности;
- количество растений;
- список существ, находящихся в клетке.

**Назначение:** хранение локального состояния конкретной позиции карты.

### 6. `Map`
**Описание:** класс карты размером \(N \times N\), состоящей из объектов `Tile`.

**Основные методы:**
- `regeneratePlants()` — регенерация растений на карте;
- `addCreature(...)` — добавление существа в клетку;
- `removeCreature(...)` — удаление существа с карты;
- `findNearestPrey(...)` — поиск ближайшей добычи для хищника;
- `findNearestPlant(...)` — поиск ближайших растений для травоядного;
- `display()` — отображение карты в консоли.

### 7. `Simulator`
**Описание:** главный управляющий класс симуляции.

**Отвечает за:**
- создание начального состояния мира;
- выполнение одного дня симуляции;
- автоматический запуск на несколько дней;
- пользовательское вмешательство;
- обработку случайных событий;
- сохранение и загрузку состояния.

### 8. `Statistics`
**Описание:** класс для накопления и вывода статистики по симуляции.

**Функции:**
- подсчёт текущего дня;
- сбор данных о популяции;
- фиксация результатов по видам;
- экспорт статистики в CSV.

## 🗺️ Легенда карты
Карта состоит из клеток, каждая из которых хранит тип местности, количество растений и список существ в данной позиции.

В отображении карты используются обозначения существ и состояния клеток, зависящие от реализации консольного вывода.

Рекомендуемая интерпретация карты:
- `H` — травоядное;
- `P` — хищник;
- `O` — всеядное;
- числовое значение или дополнительный символ клетки — количество растений либо тип местности, если это предусмотрено реализацией отображения.

Типы местности и растения влияют на доступность пищи и поведение существ во время симуляции.

## ⚙️ Возможности программы
- Инициализация карты и стартовой популяции.
- Пошаговый запуск симуляции по дням.
- Автоматический режим на несколько дней подряд.
- Случайные события, влияющие на количество растений, например дождь и засуха.
- Пользовательское вмешательство: добавление и удаление существ, изменение местности и количества растений.
- Сохранение текущего состояния и последующая загрузка.
- Выгрузка статистики симуляции в CSV-файл.
