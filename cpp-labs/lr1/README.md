## 📊 Список задач для меню:

### 1. Генератор паролей
**Тип**: строки, случайные числа, циклы

**Описание**: программа генерирует случайный пароль заданной длины с выбором типов символов.  
**Функционал**:
-	 Запрос длины пароля (от 6 до 32 символов)
-	 Выбор типов символов: цифры, прописные буквы, строчные буквы, спецсимволы
-  Генерация и вывод пароля
-  Оценка надежности пароля (слабый/средний/сильный)
-  Возможность сгенерировать несколько паролей подряд


### 2. Конвертер систем счисления
**Тип**: математические операции, циклы, строки

**Описание**: программа переводит числа между различными системами счисления.
**Функционал**:
-  Ввод числа в исходной системе счисления (от 2 до 16)
-  Выбор исходной и целевой системы счисления
-  Перевод числа в выбранную систему
-  Поддержка больших чисел (до 64 бит)
-  Вывод результата в формате: "Число X в системе Y = Z в системе W"
-  Проверка корректности введенного числа для выбранной системы


### 3. Симулятор банкомата
**Тип**: условные операторы, циклы, базовые алгоритмы

**Описание**: программа имитирует работу банкомата с основными операциями.
**Функционал**:
- Начальный баланс счета (10000 руб.)
- Меню операций: проверка баланса, снятие наличных, пополнение счета, выход
- Проверка достаточности средств при снятии
- Ограничение на сумму снятия за одну операцию (не более 5000 руб.)
- Лимит на количество операций за сеанс (не более 10)
- Вывод баланса после каждой операции


### 4. Игра "Камень, ножницы, бумага"
**Тип**: случайные числа, условные операторы, циклы

**Описание**: игра против компьютера с ведением счета.
**Функционал**:
- Выбор пользователя: камень (1), ножницы (2), бумага (3)
- Случайный выбор компьютера
- Определение победителя по правилам игры
- Ведение счета (победы/поражения/ничьи)
- Возможность играть несколько раундов подряд
- Статистика после окончания игры
- Уровень сложности (легкий/средний/сложный) — влияет на логику компьютера


### 5. Анализатор текста
**Тип**: строки, циклы, массивы символов

**Описание**: программа анализирует введенный текст и выдает статистику.
**Функционал**:
- Ввод текста (до 1000 символов)
- Подсчет: количество символов (с пробелами и без), слов, предложений
- Поиск самого длинного и самого короткого слова
- Подсчет частоты использования каждой буквы (регистр не учитывается)
- Определение, является ли текст палиндромом (игнорируя пробелы и регистр)
- Вывод статистики в удобном формате


### 6. Таймер обратного отсчета с уведомлениями
**Тип**: циклы, время, условные операторы

**Описание**: программа реализует таймер обратного отсчета с промежуточными уведомлениями. 
**Функционал**:
- Установка времени в секундах (от 10 до 3600)
- Обратный отсчет с выводом оставшегося времени каждую секунду
- Уведомления при достижении определенных моментов (50%, 25%, 10% времени)
- Звуковое оповещение (символьная анимация или текст) по окончании таймера
- Возможность паузы и продолжения отсчета
- Режим интервального таймера (несколько повторяющихся отрезков времени)
