# Лабораторная работа №5 — Симулятор салона красоты

Проект выполнен по лабораторной работе №5 по объектно-ориентированному программированию.  
Вариант 2 — симулятор салона красоты с консольным меню и хранением данных в PostgreSQL.

## Назначение проекта

Программа предназначена для автоматизации работы салона красоты.  
Реализованы учёт сотрудников, клиентов, услуг, записей, финансов салона и расчёт заработной платы сотрудников.

## Возможности программы

- просмотр сотрудников;
- просмотр клиентов;
- просмотр услуг;
- просмотр записей;
- создание новой записи;
- просмотр финансового состояния салона;
- расчёт и сохранение зарплат сотрудников.

## Структура проекта

- `include/` — заголовочные файлы классов;
- `src/` — реализация классов и логики программы;
- `sql/` — SQL-скрипты для базы данных;
- `build/` — собранный исполняемый файл;
- `CMakeLists.txt` — файл сборки проекта.

### Основные файлы и модули

- `main.cpp` — точка входа в программу;
- `Menu.*` — консольное меню;
- `DatabaseManager.*` — подключение к PostgreSQL и выполнение SQL-запросов;
- `Employee.*`, `Client.*`, `Service.*`, `Appointment.*`, `SalonState.*`, `SalaryLog.*` — основные сущности предметной области;
- `EmployeeRepository.*`, `ClientRepository.*`, `ServiceRepository.*`, `AppointmentRepository.*`, `SalonStateRepository.*`, `SalaryLogRepository.*` — работа с таблицами базы данных;
- `BookingService.*` — создание записей и проверка занятости мастеров;
- `FinanceService.*` — работа с финансовыми показателями;
- `SalaryService.*` — расчёт и сохранение зарплат.

## SQL-модуль

В папке `sql/` находятся три файла:

- `schema.sql` — создание таблиц базы данных;
- `seed.sql` — заполнение базы начальными тестовыми данными;
- `demo_queries.sql` — SQL-запросы для проверки содержимого таблиц.

## Подготовка на новом компьютере

### 1. Установить зависимости

Для Ubuntu / WSL:

```bash
sudo apt update
sudo apt install g++ cmake make postgresql postgresql-contrib libpq-dev
```

### 2. Создать базу данных

```bash
sudo -u postgres psql
```

Внутри `psql`:

```sql
CREATE DATABASE beauty_salon_db;
\q
```

### 3. Создать таблицы

Из корневой папки проекта выполнить:

```bash
psql -h localhost -U postgres -d beauty_salon_db -f sql/schema.sql
```

### 4. Загрузить начальные данные

Из корневой папки проекта выполнить:

```bash
psql -h localhost -U postgres -d beauty_salon_db -f sql/seed.sql
```

## Запуск программы

Из корневой директории проекта:

```bash
./build/beauty_salon
```

Переходить в папку `build/` не нужно.

## Проверка базы данных

Для проверки содержимого таблиц можно запустить тестовый SQL-скрипт:

```bash
psql -h localhost -U postgres -d beauty_salon_db -f sql/demo_queries.sql
```

Этот скрипт выводит:
- сотрудников;
- клиентов;
- услуги;
- записи;
- состояние салона;
- историю зарплат;
- объединённый список записей с именами клиента, мастера и услуги;
- активных сотрудников;
- клиентов, отсортированных по общей сумме трат.
