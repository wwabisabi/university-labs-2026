## 📋 Требования к программе
-	Единая программа - все задачи должны быть объединены в одном проекте
-	Интерактивное меню - при запуске отображается пронумерованный список задач с кратким описанием. Последний пункт - 0. Выход

-	Модульность - каждая задача реализуется в отдельном классе/модуле
-	Управление потоком - после выполнения задачи пользователь выбирает: выполнить снова или вернуться в главное меню

## 📋 Требования к реализации

- Обработка исключительных ситуаций
- Демонстрация понимания порядка вызова конструкторов/деструкторов

## 📊 Список задач для меню:

### 1. Каршеринг

**Описание**: разработайте систему для каршеринга, где можно брать в аренду разные типы автомобилей: эконом, бизнес-класс, минивэны, электромобили. У каждого типа своя стоимость минуты, правила бронирования и тарифы.

**Функционал**:
- Система должна поддерживать разные тарифы (поминутный, посуточный, пакетный)
- Расчет стоимости с учетом времени суток (ночью дешевле/дороже)
- Бонусная система для постоянных клиентов
- История аренд конкретного автомобиля
- Ограничение по возрасту и стажу для разных классов
- Автоматическое завершение аренды при превышении лимита времени

### 2. Онлайн-курсы с разными форматами обучения

**Описание**: разработайте систему для онлайн-школы, где есть разные типы курсов: видео-лекции, вебинары, текстовые материалы, интерактивные задания. У каждого формата своя логика прохождения и проверки.

**Функционал**:
- Курс состоит из модулей, модуль из уроков разных типов
- Прогресс прохождения курса (в процентах)
- Сертификат по окончании
- Тесты с автоматической проверкой
- Домашние задания с проверкой преподавателем
- Возможность оставлять отзывы и оценки
- Статистика по курсу (сколько человек начали/закончили)


### 3. Московское метро

**Описание**: разработайте симулятор метрополитена. Есть линии разного цвета, станции с пересадками, поезда движутся по расписанию. Нужно рассчитывать время поездки и строить маршруты.

**Функционал**:
- Линии метро с названиями и цветами
- Станции (могут принадлежать нескольким линиям)
- Пересадки между станциями с временем перехода
- Поезда, движущиеся по линиям с остановками
- Расчет времени поездки между станциями
- Поиск кратчайшего маршрута (по времени)
- Расписание движения (интервалы в часы пик/ночь)
- Аварийные ситуации (закрытие линий, задержки)

### 4. Торговый автомат

**Описание**: разработайте симулятор вендингового автомата. Автомат продает напитки (холодные и горячие), снеки. Нужно отслеживать остатки, принимать монеты/купоны, выдавать сдачу.

**Функционал**:
- Разные типы товаров (холодные, горячие, скоропортящиеся)
- Прием монет разного номинала и купюр
- Выдача сдачи (алгоритм минимальным количеством монет)
- Сроки годности (просрочка удаляется)
- Температурный режим (для горячих напитков)
- Инвентаризация и пополнение
- Статистика продаж
- Режим техобслуживания


### 5. Аэропорт

**Описание**: разработайте симулятор работы аэропорта. Есть рейсы, пассажиры с билетами, багаж, регистрация, посадка. Нужно отслеживать статусы и время.

**Функционал**:
- Разные типы пассажиров (эконом, бизнес, VIP)
- Разные классы билетов с разными правилами (багаж, приоритет)
- Регистрация на рейс (онлайн/в аэропорту)
- Сдача багажа (вес, оплата перевеса)
- Посадка с приоритетом (VIP заходят первыми)
- Задержки рейсов (погода, техсостояние)
- Трансферы между рейсами (успевает ли пассажир)
- Статистика загруженности рейсов
